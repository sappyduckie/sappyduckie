## Definitions

Wherein throughout this document the following terms are used, they are to be understood by the following definitions.
- **AI**: Systems that can generate content based on probabilistic inference.
- **Agent**: Autonomous systems that have the capacity to perform actions based on internal reasoning with a limited degree of human intervention.
- **Code**: A set of computer instructions written in a programming language.
- **Documentation**: Any written communication relating to this project that is intended to be read by humans.

## Contributions

> [!TIP]
> Contributions, human-made or otherwise, are all held to the same standards of quality. Some contributions can only be made by a human.

### Documentation

Documentation is to be exclusively written by humans. This rule is for two reasons:
1. A contributor who cannot document their contribution has not displayed that they understand what they are contributing well enough to have reviewed it, and therefore not well enough to have submitted it.
2. Documentation as defined above is the facilitated communication between humans on this project, and thus only humans should participate in it. There is a quiet cost to replacing human connection, and this project will not contribute to that.

> [!WARNING]
> Failure to comply with the rules outlined in this document may result in your contribution being arbitrarily rejected.
